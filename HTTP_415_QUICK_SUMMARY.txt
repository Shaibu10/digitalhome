# Summary of Changes for HTTP 415 Fix

## Issue
Your Flask application was returning HTTP 415 "Unsupported Media Type" errors on POST requests to:
- `/checkout` (multiple times from the logs)

## Root Cause
The `request.get_json()` method was strictly validating the Content-Type header. When there were any issues with how the header was being sent or processed, Flask would reject the request with a 415 error rather than attempting to parse the JSON data.

## Solution Applied
Modified **8 POST endpoints** in `app.py` to use more lenient JSON parsing:

### Before:
```python
data = request.get_json()
```

### After:
```python
data = request.get_json(force=True, silent=True) or {}
```

## What This Does
- `force=True`: Ignores Content-Type header validation and attempts JSON parsing
- `silent=True`: Returns None gracefully instead of raising exceptions
- `or {}`: Fallback to empty dictionary if no JSON data found
